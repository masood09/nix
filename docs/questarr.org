#+TITLE: Questarr

* Deployment

Questarr runs on =heartbeat= as the standalone Podman service
=ghcr.io/doezer/questarr:v1.4.2=. Its SQLite state is persisted at
=/var/lib/arr/questarr= on the existing Arr ZFS dataset. The existing library and
downloads trees are mounted into the container at =/data/library= and
=/data/downloads=.

The initial Questarr administrator is created manually after the service is
activated.

* Authentik Proxy Provider

Create this provider manually in Authentik and attach it to the embedded outpost:

| Setting        | Value                                                |
|----------------+------------------------------------------------------|
| External host  | =https://questarr.mantannest.com=                    |
| Internal host  | =http://heartbeat.dns.headscale.mantannest.com:8916= |
| Mode           | =proxy=                                              |
| Outpost        | Embedded outpost                                     |
| Access          | The appropriate Questarr access group                 |

The external host is also listed in the accesscontrolsystem Authentik
=forwardAuthHosts= option so Caddy routes it to the embedded outpost. The
internal host is reachable over the tailnet; heartbeat permits TCP 8916 only on
=tailscale0= for this purpose.
